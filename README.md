Academic & Thesis Supervision Management System

Sistem informasi berbasis web yang dikembangkan menggunakan PHP dan MySQL untuk mengelola proses administrasi akademik, bimbingan, pendaftaran peserta, serta ujian skripsi mahasiswa.

Fitur Utama
- Admin Dashboard: Manajemen bimbingan skripsi, verifikasi peserta skripsi, dan penjadwalan ujian skripsi.
- Master Data Management: Pengelolaan data Dosen, Mahasiswa, dan Penasihat Akademik (CRUD).
- Autentikasi & Otorisasi: Sistem login multi-peran dengan validasi sesi yang aman.

Teknologi yang Digunakan
- Backend: PHP
- Database: MySQL
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Web Server: Apache (XAMPP)
